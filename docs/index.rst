|addon| for the |NCS|
#####################

The |addon| for the |NCS| provides support for developing Matter applications based on the Matter stack.
In combination with the |NCS|, the |addon| allows for development of Matter accessories and applications.

.. note::
   This documentation describes the ``preview-thread-hdr`` release of the |addon|.
   It is an experimental preview intended for evaluating Thread HDR (High Data Rate) support.

   To learn more, see :ref:`ncs_matter_thread_hdr_preview`.

For additional context on other solutions, refer to the following resources:

* :ref:`Matter overview <ug_matter_intro_overview>` — Introduction to the Matter protocol and its use in the |NCS|.
* :ref:`ug_matter_overview_architecture` — How Matter accessories, controllers, and networks fit together.
* `Matter add-on repository`_ — Source code for the Matter add-on.
